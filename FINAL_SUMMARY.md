## 🎯 Практическое применение:

### 1. Навигация по графу:
```cypher
// Найти все концепции, которые изучает студент
MATCH (st:Student)-[:STUDIES]->(l:Lesson)-[:TEACHES]->(c:Concept)
WHERE st.name = "Денис Ахмедов"
RETURN c.name
```

### 2. Поиск похожих студентов:
```cypher
// Студенты, изучающие те же концепции
MATCH (st1:Student)-[:STUDIES]->(:Lesson)-[:TEACHES]->(c:Concept)
      <-[:TEACHES]-(:Lesson)<-[:STUDIES]-(st2:Student)
WHERE st1.name = "Денис Ахмедов" AND st1 <> st2
RETURN st2.name, count(c) as commonConcepts
ORDER BY commonConcepts DESC
```

### 3. Анализ популярности концепций:
```cypher
// Самые популярные концепции
MATCH (l:Lesson)-[:TEACHES]->(c:Concept)<-[:USES]-(s:Submission)
RETURN c.name, 
       count(DISTINCT l) as lessons, 
       count(DISTINCT s) as submissions
ORDER BY lessons DESC, submissions DESC
LIMIT 10
```

### 4. Путь обучения студента:
```cypher
// Визуализация прогресса
MATCH path = (st:Student)-[:STUDIES]->(l:Lesson)-[:TEACHES]->(c:Concept)
WHERE st.name = "Денис Ахмедов"
RETURN path
```
