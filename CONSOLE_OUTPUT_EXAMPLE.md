## Возможные проблемы

### ⚠️ Урок ID не найден

```
⚠️ Урок ID не найден, пропускаю анализ урока
```

**Причина:** В HTML нет атрибута `data-lesson-id`

**Решение:** Проверить селектор в `src/parser.ts`

### ⚠️ Видео не найдены

```
   🎥 Найдено видео: 0
   ℹ️ Видео не найдены, парсим весь текст урока...
```

**Причина:** Урок текстовый или видео встроены иначе

**Решение:** Агент использует весь текст урока как fallback

### ❌ Ошибка при загрузке урока

```
❌ Ошибка при загрузке урока: [описание]
⚠️ Продолжаю проверку без контекста урока...
```

**Причина:** Таймаут, 404, или другая ошибка

**Решение:** Проверка продолжится без контекста урока

## Как интерпретировать вывод

### Хороший результат:
- ✅ Найдено 1+ видео
- ✅ Описания не пустые (>100 символов каждое)
- ✅ Выжимка создана (>200 символов)
- ✅ Выжимка попала в промпт AI
- ✅ AI ссылается на урок в комментарии

### Требует внимания:
- ⚠️ Видео не найдены (но есть текст урока)
- ⚠️ Описания пустые (нужно обновить селекторы)
- ⚠️ Выжимка слишком короткая (<100 символов)

### Критическая ошибка:
- ❌ Ошибка при загрузке урока
- ❌ Ошибка при создании выжимки
- ❌ Выжимка не попала в промпт AI
