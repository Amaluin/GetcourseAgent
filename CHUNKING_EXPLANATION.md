# 📚 Разбиение Урока на Чанки (Chunks)

## ✅ Да, текстовая часть урока разбирается на чанки!

## 🔄 Процесс разбиения:

### 1️⃣ **Парсинг урока** (`src/lesson-parser.ts`)

Функция `getLessonContent()` извлекает текст урока и создает **детальные секции** (чанки).

### 2️⃣ **Создание секций** (функция `createDetailedSections`)

Урок автоматически разбивается на секции по одной из **трех стратегий**:

#### **Стратегия 1: По видео** (если в уроке есть видео)
```typescript
// Для каждого видео создается отдельная секция:
{
  sectionNumber: 1,
  title: "Видео 1",
  content: "текст до видео + текст после видео",
  videoUrl: "https://...",
  beforeVideo: "текст до видео",
  afterVideo: "текст после видео"
}
```

#### **Стратегия 2: По заголовкам** (если нет видео, но есть структура)
```typescript
// Если в тексте есть заголовки (h1-h6 или строки из заглавных букв),
// урок разбивается по ним:
{
  sectionNumber: 1,
  title: "Введение",
  content: "весь текст под этим заголовком...",
  beforeVideo: "текст",
  afterVideo: ""
}
```

**Условия для заголовков:**
- Строка начинается с заглавной буквы
- Длина 5-100 символов
- Не заканчивается точкой или запятой
- После заголовка идет минимум 200 символов текста

#### **Стратегия 3: Равные части по 2000 символов** (если нет структуры)
```typescript
// Если нет ни видео, ни заголовков, текст режется на куски по 2000 символов:
const chunkSize = 2000;
for (let i = 0; i < fullText.length; i += chunkSize) {
  const chunk = fullText.slice(i, i + chunkSize);
  sections.push({
    sectionNumber: index + 1,
    title: "Часть 1" (или первая строка чанка),
    content: chunk
  });
}
```

### 3️⃣ **Что происходит дальше?**

Каждая секция (чанк) обрабатывается отдельно:

```typescript
// src/graphrag/neo4j-client.ts → addLesson()

for (const section of detailedSections) {
  // 1. Извлекаются ключевые слова
  const keywords = extractKeywords(section.content);
  
  // 2. Создается embedding (вектор) для семантического поиска
  const embedding = await createEmbedding(section.content);
  
  // 3. Секция сохраняется в Neo4j как отдельный узел
  await saveLessonSection(session, {
    id: `${lessonId}-section-${section.sectionNumber}`,
    lessonId: lessonId,
    sectionNumber: section.sectionNumber,
    title: section.title,
    content: section.content,
    keywords: keywords,
    embedding: embedding,
    ...
  });
}
```

## 🎯 Зачем разбивать на чанки?

### 1. **Точный поиск**
Вместо поиска по всему уроку (59,478 символов), ищем по конкретным секциям:

```bash
npm run search "как настроить webhook в n8n"
```

Результат:
```
✅ Найдено 1 релевантная секция:
📚 Урок: "AN08 - Webhooks и API"
📍 Секция 2: Настройка в N8N
⭐ Релевантность: 87.3%
```

### 2. **Контекст для AI**
AI получает **только релевантные** чанки, а не весь урок целиком:

```typescript
// Вместо отправки 59,478 символов:
❌ "Весь текст урока..."

// AI получает только нужную секцию:
✅ "Секция 2: Настройка в N8N - Теперь давайте настроим..."
```

### 3. **Эффективные embeddings**
Ollama создает более точные векторы для коротких текстов:

```typescript
// Embedding для короткого чанка (2000 символов):
✅ Высокая точность, быстрое создание

// Embedding для всего урока (59,478 символов):
❌ Низкая точность, долгое создание, урезается до 8000 символов
```

### 4. **Навигация по графу**
Каждая секция - это отдельный узел в Neo4j:

```cypher
MATCH (l:Lesson)-[:HAS_SECTION]->(s:LessonSection)-[:MENTIONS]->(k:Keyword)
WHERE k.name = "webhook"
RETURN l.title, s.sectionNumber, s.title
```

Результат:
```
Урок: "AN08", Секция: 2, Заголовок: "Настройка в N8N"
```

## 💡 Преимущества текущего подхода:

✅ **Автоматическое разбиение** - не нужно вручную настраивать  
✅ **Адаптивность** - использует структуру урока (видео, заголовки)  
✅ **Семантический поиск** - embeddings для каждого чанка  
✅ **Точность** - AI получает только релевантный контекст  
✅ **Навигация** - можно найти "после какого видео" упоминался термин  
✅ **Масштабируемость** - чанки обрабатываются параллельно

- 🔍 **Каждый чанк** имеет свой embedding для поиска
- 🏷️ **Каждый чанк** имеет свои ключевые слова
- 🔗 **Каждый чанк** связан с уроком в графе Neo4j
