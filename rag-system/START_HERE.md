# 🎯 С чего начать? Выбор подхода для RAG системы

## 📚 Доступные подходы

У вас есть **3 варианта** реализации RAG системы для GetCourse Agent:

---

## 1️⃣ Supabase + pgvector (классический подход)

**Файл**: [`README.md`](./README.md)

### Что это?
- Managed PostgreSQL база (Supabase)
- Векторный поиск через pgvector
- OpenAI embeddings
- SQL запросы

### Преимущества
✅ Managed решение (не нужно управлять сервером)  
✅ Простой векторный поиск  
✅ Хорошая документация  
✅ Быстрая настройка  

### Недостатки
❌ Нет графа знаний  
❌ Стоимость: $25-35/мес  
❌ Ограничения Free tier (500 MB)  

### Когда использовать?
- Вам достаточно векторного поиска
- Не нужны сложные связи между сущностями
- Хотите managed решение
- Бюджет позволяет $25-35/мес

**👉 Читайте**: [`README.md`](./README.md) и [`SETUP_GUIDE.md`](./SETUP_GUIDE.md)

---

## 2️⃣ Graphiti + Neo4j + Ollama (полностью бесплатный!) 🏆

**Файл**: [`README_GRAPHRAG.md`](./README_GRAPHRAG.md)

### Что это?
- Neo4j граф знаний
- Graphiti для GraphRAG
- **Ollama + nomic-embed-text** (локальные embeddings)
- Groq API (бесплатный LLM)

### Преимущества
✅ **$0/месяц** - полностью бесплатно! 🎉  
✅ Полноценный граф знаний  
✅ Автоматическое извлечение концепций  
✅ Визуализация графа (Neo4j Browser)  
✅ Приватность (всё локально)  
✅ Работает оффлайн  
✅ Быстрые embeddings (~50ms)  

### Недостатки
⚠️ Нужно управлять Neo4j (Docker)  
⚠️ Требует больше настройки  

### Когда использовать?
- Хотите **бесплатное** решение
- Нужен полноценный граф знаний
- Важна приватность данных
- Готовы настроить Docker

**👉 Читайте**: [`README_GRAPHRAG.md`](./README_GRAPHRAG.md) и [`OLLAMA_MIGRATION.md`](./OLLAMA_MIGRATION.md)

---

## 3️⃣ Гибридный подход (лучшее из двух миров)

**Файл**: [`README_HYBRID.md`](./README_HYBRID.md)

### Что это?
- Supabase для векторного поиска (быстро)
- Neo4j для графа знаний (мощно)
- Ollama для embeddings (бесплатно)
- Синхронизация между системами

### Преимущества
✅ Быстрый векторный поиск (Supabase)  
✅ Мощный граф знаний (Neo4j)  
✅ Бесплатные embeddings (Ollama)  
✅ Лучшее качество проверки  

### Недостатки
⚠️ Сложнее в настройке  
⚠️ Нужно управлять двумя БД  
⚠️ Стоимость Supabase: $25/мес  

### Когда использовать?
- Нужно максимальное качество
- Важна скорость векторного поиска
- Нужен граф знаний
- Бюджет позволяет $25/мес

**👉 Читайте**: [`README_HYBRID.md`](./README_HYBRID.md)

**Читайте**: [`QUICK_START.md`](./QUICK_START.md)

---

### Вариант 2: Graphiti + Ollama (20 минут) 🏆

```bash
# 1. Установите Ollama
curl -fsSL https://ollama.com/install.sh | sh
ollama pull nomic-embed-text

# 2. Запустите Neo4j
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/password neo4j:latest

# 3. Установите зависимости
pip install graphiti-core ollama

# 4. Настройте .env
echo "USE_OLLAMA_EMBEDDINGS=true" >> .env
echo "NEO4J_URI=bolt://localhost:7687" >> .env

# 5. Запустите агента
npm start
```

**Читайте**: [`README_GRAPHRAG.md`](./README_GRAPHRAG.md)

## ❓ FAQ

### В чем разница между подходами?
- **Supabase**: только векторный поиск
- **Graphiti**: полноценный граф знаний
- **Гибрид**: оба варианта вместе

### Какой подход самый быстрый?
**Гибрид** - векторный поиск в Supabase + граф в Neo4j

### Какой подход самый дешевый?
**Graphiti + Ollama** - $0/месяц

### Какой подход самый качественный?
**Гибрид** - использует все преимущества обеих систем

### Можно ли переключаться между подходами?
Да! Все подходы совместимы. Можете начать с Supabase, потом добавить Neo4j.

### Нужен ли мне граф знаний?
Если вы хотите:
- Автоматическое извлечение концепций
- Связи между уроками
- Визуализацию знаний
- Более глубокий анализ

То **да**, граф знаний очень полезен.

## 🧪 Хотите протестировать?

Перед выбором подхода можете запустить тест GraphRAG на одной работе:

```bash
# 1. Запустите Ollama и Neo4j
ollama serve &
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/password neo4j:latest

# 2. Установите зависимости
pip install neo4j
npm install axios

# 3. Запустите тест
ts-node rag-system/test-single-submission.ts
```

**Результат**: Тест создаст урок, работу студента, извлечет концепции, сохранит в БД и покажет статистику!
