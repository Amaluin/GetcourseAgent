## 📊 Статистика чанков:

```
┌─────────────────────────────────────────────────────────┐
│                РАЗМЕРЫ ЧАНКОВ                            │
├─────────────────────────────────────────────────────────┤
│  Стратегия             │ Размер чанка   │ Количество    │
│────────────────────────┼────────────────┼───────────────│
│  По видео              │ 500-3000 сим.  │ = кол-во видео│
│  По заголовкам         │ 200-5000 сим.  │ = кол-во загол│
│  Равные части          │ 2000 сим.      │ текст / 2000  │
└─────────────────────────────────────────────────────────┘

ПРИМЕР ДЛЯ УРОКА 59,478 СИМВОЛОВ:

С видео (2 видео):
  → 2 секции по 29,739 символов

Без видео, с заголовками (5 заголовков):
  → 5 секций по ~11,895 символов

Без структуры:
  → 30 секций по 2,000 символов
```

## 🎯 Преимущества чанкинга:

```
┌──────────────────────────────────────────────────────┐
│            БЕЗ ЧАНКОВ                                 │
├──────────────────────────────────────────────────────┤
│  📚 Весь урок: 59,478 символов                       │
│  🔍 Поиск: по всему тексту сразу                     │
│  🧠 Embedding: 1 вектор для всего урока              │
│  ⚠️ Проблемы:                                         │
│     • Низкая точность поиска                         │
│     • Нет контекста "где именно" упоминалось         │
│     • AI получает весь урок (дорого, медленно)       │
│     • Нет навигации по структуре                     │
└──────────────────────────────────────────────────────┘
                         VS
┌──────────────────────────────────────────────────────┐
│            С ЧАНКАМИ                                  │
├──────────────────────────────────────────────────────┤
│  📦 2 секции по ~30,000 символов                     │
│  🔍 Поиск: по каждой секции отдельно                 │
│  🧠 Embeddings: 2 вектора (точнее!)                  │
│  ✅ Преимущества:                                     │
│     • Высокая точность поиска                        │
│     • Точный ответ "в секции 2 после видео"          │
│     • AI получает только нужную секцию               │
│     • Навигация: урок → секция → видео               │
└──────────────────────────────────────────────────────┘
```

## 🚀 Как это использовать:

```bash
# 1. Загрузить уроки (чанки создаются автоматически)
$env:GRAPHRAG_ENABLED="true"
npm run start

# 2. Проверить структуру
npm run visualize-graph
# → Показывает количество секций на урок

# 3. Посмотреть содержимое чанков
npm run inspect-kb
# → Показывает размер каждого чанка

# 4. Искать по чанкам
npm run search "webhook n8n"
# → Находит конкретную секцию
```

## 💡 Итог:

✅ **Каждый урок автоматически разбивается на чанки**  
✅ **Каждый чанк - это отдельная секция с embeddings**  
✅ **Поиск работает по чанкам, а не по всему уроку**  
✅ **AI получает только релевантные чанки**  
✅ **Навигация: можно найти "после какого видео" был термин**

**Это полноценная база знаний с чанкингом!** 🎉
