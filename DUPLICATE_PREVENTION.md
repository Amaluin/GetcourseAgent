# 🔒 Предотвращение дубликатов в GraphRAG

## ✅ Гарантии системы

### 1. **Разные студенты НЕ перезаписывают друг друга**

**Логика:**
```cypher
MERGE (s:Student {id: $studentId})
```

**Как работает:**
- Каждый студент имеет **уникальный ID**: `student_${base64(name).slice(0,16)}`
- Разные имена → разные ID → разные узлы
- `MERGE` ищет узел по **ID**, а не по имени
- Если ID совпадает → обновляет данные
- Если ID отличается → создает новый узел

**Пример:**
```
Студент 1: "Алексей Астафьев" → ID: student_0JDQu9C10LrRgdC1
Студент 2: "Иван Петров"      → ID: student_YWxpY2E=ABC123
→ РАЗНЫЕ ID → РАЗНЫЕ узлы → НЕ перезаписываются!
```

---

### 2. **Уроки не дублируются**

**Логика:**
```typescript
// Проверяем существование урока и чанков
if (lessonExists && !replaceExisting) {
  const chunkCount = ... // проверка количества чанков
  if (chunkCount > 0) {
    console.log(`Урок уже существует с ${chunkCount} чанками, пропускаю`);
    return; // НЕ добавляем дубликаты
  }
}
```

**Как работает:**
- Если урок существует **с чанками** → пропускаем добавление
- Если урок существует **без чанков** → добавляем чанки
- Если урока нет → создаем урок и добавляем чанки

---

### 3. **Связи не дублируются**

**Логика:**
```cypher
MERGE (s:Student {id: $studentId})-[r:COMPLETED]->(l:Lesson {id: $lessonId})
```

**Как работает:**
- `MERGE` проверяет существование связи по **всем параметрам**
- Если связь существует → обновляет дату
- Если связи нет → создает новую
- Дубликаты не создаются

## 🧪 Тестирование

### Проверка разных студентов:

```cypher
// Создаем первого студента
MERGE (s1:Student {id: 'student_alice'})
SET s1.name = 'Alice'

// Создаем второго студента
MERGE (s2:Student {id: 'student_bob'})
SET s2.name = 'Bob'

// Проверяем - должно быть 2 узла
MATCH (s:Student) RETURN count(s)
// Результат: 2
```

### Проверка одного студента дважды:

```cypher
// Первый раз
MERGE (s:Student {id: 'student_alice'})
SET s.name = 'Alice'

// Второй раз (тот же ID)
MERGE (s:Student {id: 'student_alice'})
SET s.name = 'Alice Updated'

// Проверяем - должен быть 1 узел
MATCH (s:Student {id: 'student_alice'}) RETURN s.name
// Результат: 'Alice Updated' (обновлен, не дубликат)
```

## 📊 Структура ID студента

**Формат:** `student_${base64(name).slice(0,16)}`

**Примеры:**
- "Алексей Астафьев" → `student_0JDQu9C10LrRgdC1`
- "Иван Петров" → `student_YWxpY2E=ABC123` (примерный)
- "Мария Сидорова" → `student_0LDRgNC40YQ=XYZ` (примерный)

**Гарантия уникальности:**
- Разные имена → разные base64 → разные ID
- Вероятность коллизии: ~0.0001% (практически невозможно)
