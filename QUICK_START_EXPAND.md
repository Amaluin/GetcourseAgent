# 🚀 Быстрый старт: Раскрытие скрытых блоков

## ✅ Что реализовано

Агент теперь **автоматически раскрывает все скрытые блоки** (спойлеры, аккордеоны) на странице урока перед парсингом.

## 📺 Что вы увидите в консоли

```
============================================================
📚 ШАГ 1: Анализ урока (ID: 344609228)
============================================================
📚 Загружаю содержимое урока ID: 344609228...
   📖 Урок: "AA06. Фильтры, задержки и условия"
   🔗 URL: https://university.zerocoder.ru/...
   📄 Объем текста ДО раскрытия: 1200 символов
   🔓 Раскрываю скрытые блоки...
   ✅ Раскрыто элементов: 5
   🔧 Применены JavaScript манипуляции для раскрытия скрытых блоков
   📄 Объем текста ПОСЛЕ раскрытия: 8500 символов (+7300)
                                                      ^^^^^^
                                                      Это хорошо!
```

## ✅ Как проверить, что работает

### 1. Объем текста увеличился

```
📄 Объем текста ДО раскрытия: 1200 символов
📄 Объем текста ПОСЛЕ раскрытия: 8500 символов (+7300)
```

**Хорошо:** Прирост >3000 символов  
**Плохо:** Прирост <500 символов (возможно, блоки не раскрылись)

### 2. Раскрыто несколько элементов

```
✅ Раскрыто элементов: 5
```

**Хорошо:** >3 элементов  
**Плохо:** 0 элементов (нужно добавить селекторы)

### 3. Описания к видео не пустые

```
✅ Видео 1: "Введение в фильтры"
   └─ Описание: 850 символов (до: 120, после: 730)
                ^^^^^^^^^^^^
                Много текста — хорошо!
```

## 🔧 Режим отладки

Если блоки не раскрываются, включите режим отладки:

### 1. Добавьте в `.env`:

```ini
DEBUG_LESSON=true
```

### 2. Запустите агента:

```bash
npm start
```

### 3. Проверьте файлы:

```bash
# Откройте скриншот урока
start debug_lesson_344609228.png

# Откройте HTML урока в браузере
start debug_lesson_344609228.html
```

### 4. Проверьте визуально:

- Все ли блоки раскрыты на скриншоте?
- Видны ли стрелки ▶ (значит не раскрылось)?
- Есть ли текст, который был скрыт?

## ⚠️ Если не работает

### Проблема: Раскрыто 0 элементов

```
✅ Раскрыто элементов: 0
📄 Объем текста ПОСЛЕ раскрытия: 1200 символов (+0)
```

**Решение:**

1. Включите `DEBUG_LESSON=true`
2. Откройте `debug_lesson_XXXXX.html` в браузере
3. Найдите нераскрытый блок (Inspect Element)
4. Посмотрите его класс или селектор
5. Сообщите мне — я добавлю селектор

### Проблема: Прирост текста маленький

```
📄 Объем текста ПОСЛЕ раскрытия: 1500 символов (+300)
```

**Причины:**
- Урок действительно короткий
- Блоки раскрылись, но контент загружается через AJAX
- Нестандартная реализация спойлеров

**Решение:** Включите отладку и проверьте HTML

## 📝 Примечание

Функция `expandAllHiddenBlocks()` пытается раскрыть блоки тремя способами:

1. **Клик по элементам** (стрелки, кнопки, ссылки)
2. **JavaScript манипуляции** (убирает `display: none`, классы `hidden`)
3. **Aria атрибуты** (устанавливает `aria-expanded="true"`)

Если ни один способ не сработал — нужна ручная настройка селекторов для конкретного урока.
