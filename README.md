# 🤖 GetCourse AI Agent

Автоматический ИИ-агент для проверки домашних заданий на платформе GetCourse.

## 🎯 Возможности

- ✅ Автоматическая авторизация в GetCourse
- ✅ Сканирование ленты непроверенных ответов
- ✅ **Анализ урока перед проверкой** (NEW!)
  - Переход к уроку студента
  - **Автоматическое раскрытие скрытых блоков** (спойлеры, аккордеоны)
  - Извлечение текстовых описаний к видео
  - Создание выжимки урока через AI
- ✅ Чтение текста задания и идеального ответа
- ✅ Анализ текстовых ответов студентов
- ✅ Анализ JSON файлов (для заданий по n8n, API и т.д.)
- ✅ Анализ скриншотов через Google Gemini Vision API
- ✅ Генерация персонализированных комментариев (обращение по имени)
- ✅ Автоматическое принятие/отклонение заданий
- ✅ Режим DRY_RUN для безопасного тестирования

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```ini
# Настройки GetCourse
GC_URL=https://university.zerocoder.ru/cms/system/login
GC_LOGIN=ваш_email@example.com
GC_PASSWORD=ваш_пароль
GC_STREAM_URL=https://university.zerocoder.ru/teach/control/answers/unanswered

# API ключи (выберите один или несколько)
GROQ_API_KEY=gsk_...           # Рекомендуется (быстро и бесплатно)
OPENAI_API_KEY=sk-...          # Альтернатива Groq
GEMINI_API_KEY=AI...           # Для анализа скриншотов (опционально)
```

### 3. Получение API ключей

#### Groq (рекомендуется)
1. Зарегистрируйтесь на https://console.groq.com
2. Создайте API ключ (бесплатно, быстрая модель Llama 3.3 70B)

#### Google Gemini (для анализа скриншотов)
1. Перейдите на https://aistudio.google.com/app/apikey
2. Создайте API ключ (бесплатно, 1500 запросов/день)

### 4. Запуск

```bash
npm start
```

## 🛡️ Безопасность

По умолчанию агент работает в режиме **DRY_RUN** (тестовый режим):
- Открывает браузер (видимый)
- Находит задания
- Генерирует комментарии
- **Вписывает комментарий в поле, но НЕ нажимает кнопки**

Чтобы включить боевой режим:
1. Откройте `src/index.ts`
2. Измените `const DRY_RUN = true;` на `const DRY_RUN = false;`

## 🔧 Как это работает

1. **Авторизация**: Playwright запускает браузер и входит в ваш аккаунт GetCourse
2. **Сканирование**: Агент переходит на страницу `/teach/control/answers/unanswered`
3. **Парсинг**: Для каждого задания извлекает:
   - Имя студента
   - Текст ответа
   - Прикрепленные файлы (JSON, изображения)
   - ID урока
4. **Анализ урока** (NEW!):
   - Переходит к уроку студента
   - Находит все видео и текстовые описания к ним
   - Создает краткую выжимку (200-300 слов) через AI
   - Возвращается в ленту ответов
5. **Загрузка задания**:
   - Открывает модальное окно "Задание и идеальный ответ"
6. **Анализ AI**:
   - Отправляет все данные в Groq API (Llama 3.3 70B):
     - Выжимку урока (что объяснялось)
     - Текст задания (что требуется)
     - Идеальный ответ (эталон)
     - Работу студента (текст, файлы, скриншоты)
   - Если есть скриншоты — анализирует через Google Gemini Vision
   - Если есть JSON файлы — скачивает и читает содержимое
7. **Вердикт**: Генерирует персонализированный комментарий и решение (accept/reject)
8. **Действие**: Вписывает комментарий и нажимает кнопку (если не DRY_RUN)

## 🎓 Примеры использования

### Проверка заданий по n8n
Агент автоматически:
- Скачивает JSON файл с workflow
- Анализирует структуру (ноды, connections, credentials)
- Сравнивает с идеальным ответом
- Проверяет наличие всех требуемых блоков

### Проверка заданий со скриншотами
Если включен Gemini API:
- Анализирует содержимое скриншотов
- Проверяет правильность настроек интерфейса
- Читает текст на изображениях

## ⚙️ Настройка промпта

Промпт находится в файле `src/ai.ts` (функция `checkHomework`).

Вы можете настроить:
- Строгость проверки
- Стиль комментариев
- Критерии принятия/отклонения

## 🐛 Отладка

Если агент не находит задания:
1. Проверьте, что URL в `.env` правильный
2. Откройте `src/parser.ts` и изучите селекторы
3. Запустите с `headless: false` (по умолчанию) и наблюдайте за браузером

Если не работает ввод комментария:
1. Проверьте файл `debug_screenshot.png` (создается автоматически)
2. Изучите HTML структуру в `debug_source.html`
