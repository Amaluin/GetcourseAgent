# 📚 План реализации: Анализ урока перед проверкой

## ✅ Что реализовано

### 1. Новый модуль `src/lesson-parser.ts`

#### Функция `getLessonContent(page, lessonId)`
Загружает содержимое урока и извлекает:
- **Заголовок урока**
- **Видео блоки** (YouTube, Vimeo, Rutube)
- **Текстовые описания** к каждому видео (до и после)
- **Изображения** (примеры из урока)
- **Прикрепленные файлы**
- **Выжимку урока** через AI (суммаризация)

#### Функция `summarizeLessonContent(videoSections, title)`
Создает краткую выжимку (200-300 слов) через Groq/OpenAI:
- Какие темы рассматривались
- Какие инструменты использовались
- Какие конкретные действия показывались
- Какой результат должен получиться

### 2. Обновленный процесс проверки

```
1. Извлечь lessonId из ленты ответов
2. Перейти к уроку по прямой ссылке
3. Парсить текстовые описания к видео
4. Создать выжимку через AI
5. Вернуться в ленту ответов
6. Загрузить "Задание и идеальный ответ"
7. Проверить работу студента с учетом:
   - Выжимки урока (что объяснялось)
   - Текста задания (что требуется)
   - Идеального ответа (эталон)
```

### 3. Обновленный промпт для AI

Теперь AI получает:
```
=== ЧТО ОБЪЯСНЯЛОСЬ В УРОКЕ ===
[Выжимка урока]

=== ТЕКСТ ЗАДАНИЯ ===
[Что требуется сделать]

=== ИДЕАЛЬНЫЙ ОТВЕТ ===
[Эталон]

=== РАБОТА СТУДЕНТА ===
[Текст, файлы, скриншоты]
```

AI проверяет:
1. Соответствует ли работа тому, что объяснялось в уроке
2. Выполнены ли требования задания
3. Похожа ли работа на идеальный ответ

## 🔍 Отладка

### Если не находит lessonId

**Проверить:**
```typescript
// В src/parser.ts
const lessonId = await wrapper.getAttribute('data-lesson-id') || '';
console.log(`DEBUG: lessonId = "${lessonId}"`);
```

**Альтернативный способ:**
Извлечь ID из ссылки:
```typescript
const lessonLink = await wrapper.locator('.show-lesson-link').getAttribute('href');
// Ссылка: /teach/control/answers/unanswered/lesson/344609228
const lessonId = lessonLink?.match(/lesson\/(\d+)/)?.[1] || '';
```

---

### Если не находит текстовые описания

**Проверить HTML структуру:**
1. Открыть урок вручную
2. Нажать F12 (DevTools)
3. Найти видео элемент
4. Изучить соседние элементы (до и после)

**Обновить селекторы в `lesson-parser.ts`:**
```typescript
// Ищем текст ПОСЛЕ видео
const descriptionAfter = await iframe.locator('xpath=following-sibling::div[1]')
  .innerText()
  .catch(() => '');
```

---

### Если выжимка не создается

**Проверить:**
1. Есть ли API ключ (GROQ_API_KEY или OPENAI_API_KEY)
2. Не превышен ли лимит токенов (текст обрезается до 8000 символов)
3. Нет ли ошибки API

**Fallback:**
Если AI не работает, используется первые 500 символов текста урока.

## 💡 Рекомендации

### Для точности проверки:
1. **Всегда загружать урок** — даже если есть идеальный ответ
2. **Использовать выжимку** — не весь текст урока (экономия токенов)
3. **Сравнивать с уроком** — не придумывать требования

### Для скорости:
1. **Кэшировать выжимки** — один урок проверяют много студентов
2. **Ограничить текст** — максимум 8000 символов
3. **Использовать Groq** — быстрее и дешевле OpenAI

### Для надежности:
1. **Fallback на весь текст** — если не нашли видео
2. **Обработка ошибок** — если урок не загрузился
3. **Возврат в ленту** — после каждого урока
