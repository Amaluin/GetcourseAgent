## 🏗️ Архитектура (кратко)

```
GetCourse Platform
        ↓
GetCourse Agent (Playwright)
        ↓
RAG Orchestrator
   ├── Lesson Cache (Supabase)
   ├── Vector Search (pgvector)
   └── AI Checker (Groq + примеры)
        ↓
Student Feedback
```

### Workflow (упрощенно)

**Первая проверка** (холодный старт):
```
Парсинг урока (20с) → Векторизация (2с) → Кэш (1с) → AI проверка (10с)
= 33 секунды
```

**Последующие проверки** (горячий кэш):
```
Кэш (0.5с) → Поиск похожих работ (1с) → AI проверка (10с)
= 11.5 секунды ⚡
```
