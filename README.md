## 🎯 Возможности

### Основной функционал
- ✅ **Автоматическая авторизация** в GetCourse с сохранением сессии
- ✅ **Сканирование ленты** непроверенных ответов студентов
- ✅ **Анализ урока** перед проверкой:
  - Автоматическое раскрытие скрытых блоков (спойлеры, аккордеоны)
  - Извлечение текстовых описаний к видео
  - Создание AI-выжимки урока (200-300 слов)
- ✅ **Чтение задания и идеального ответа** из модального окна
- ✅ **Мультимодальный анализ**:
  - Текстовые ответы (Groq Llama 3.3 70B)
  - JSON файлы (для заданий по n8n, API)
  - Скриншоты (Google Gemini Vision API)
- ✅ **Персонализированные комментарии** с обращением по имени
- ✅ **Автоматическое принятие/отклонение** заданий
- ✅ **Режим DRY_RUN** для безопасного тестирования

### GraphRAG система
- 🗄️ **База знаний** на Neo4j с векторными embeddings
- 🔍 **Семантический поиск** по урокам и работам студентов
- 📊 **Трекинг прогресса** студентов
- 🔗 **Связи между концепциями** и уроками
- 💾 **Кэширование уроков** (избежание повторного парсинга)

### KAG интеграция
- 🧠 **Система рассуждений** (OpenSPG/KAG)
- 📚 **Образовательная схема** (студенты, уроки, задания, концепции)
- 🔄 **Автоматическое извлечение концепций** из уроков
- 📈 **Анализ готовности студентов** к заданиям

## 🛠️ Технологии

### Основной стек
- **TypeScript** - основной язык разработки

### AI и ML
- **Groq API** (Llama 3.3 70B) - основная модель для проверки

- **OpenSPG/KAG** - система рассуждений и граф знаний

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```ini
# GetCourse настройки
GC_URL=https://university.zerocoder.ru/cms/system/login
GC_LOGIN=ваш_email@example.com
GC_PASSWORD=ваш_пароль
GC_STREAM_URL=https://university.zerocoder.ru/teach/control/answers/unanswered

# AI API ключи
GROQ_API_KEY=gsk_...           # Рекомендуется (быстро и бесплатно)
OPENAI_API_KEY=sk-...          # Альтернатива Groq
GEMINI_API_KEY=AI...           # Для анализа скриншотов

# GraphRAG (Neo4j)
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=neo4j@openspg
GRAPHRAG_ENABLED=true          # Включить GraphRAG

# Embeddings
EMBEDDING_PROVIDER=ollama      # или 'openai'
OLLAMA_BASE_URL=http://localhost:11434
EMBEDDING_MODEL=nomic-embed-text

# KAG/OpenSPG (опционально)
OPENSPG_SERVER_URL=http://localhost:8887
```

### 3. Запуск Neo4j (для GraphRAG)

```bash
# Docker
docker run -d \
  --name neo4j \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/neo4j@openspg \
  neo4j:latest
```

### 4. Запуск Ollama (для локальных embeddings)

```bash
# Установите Ollama с https://ollama.ai
ollama pull nomic-embed-text
```

### 5. Запуск агента

```bash
# Тестовый режим (DRY_RUN)
npm start

# Поиск в базе знаний
npm run search "GitHub Actions"

# Визуализация графа
npm run visualize-graph
```

Интеграция с AI моделями:

## 🔮 GraphRAG система

### Возможности
- **Хранение уроков** в графе знаний с векторными embeddings
- **Семантический поиск** по содержимому уроков
- **Трекинг студентов** и их работ
- **Связи между концепциями** и уроками
- **Извлечение концепций** из текста через AI
- **Персональные рекомендации** для студентов

### Структура данных

```
Lesson ──HAS_SECTION──> LessonSection ──HAS_EMBEDDING──> Embedding
  │                                                           │
  ├──HAS_CONCEPT──> Concept ◄──RELATED_TO── Concept          │
  │                                                           │
  └──HAS_SUBMISSION──> Submission ──SUBMITTED_BY──> Student   │
                                                              │
Student ──HAS_STATS──> StudentStats                          │
                                                              │
                    Semantic Search ─────────────────────────┘
```

### Использование

```typescript
// Инициализация
const graphRAG = await GraphRAG.initGraphRAG();

// Добавление урока
await GraphRAG.addLesson({
  id: 'lesson-123',
  title: 'GitHub Actions',
  content: '...',
  summary: '...'
});

// Поиск
const results = await GraphRAG.getLessonContext('lesson-123', 'query');

// Статистика студента
const stats = await GraphRAG.getStudentStats('Иван Иванов');
```

### Модули GraphRAG

- **`chunking.ts`** - разбиение текста на чанки
- **`embeddings.ts`** - создание векторных представлений
- **`neo4j-client.ts`** - базовый клиент Neo4j
- **`neo4j-advanced.ts`** - продвинутые операции (семантический поиск, трекинг)
- **`semantic-search.ts`** - семантический поиск с reranking
- **`knowledge-base.ts`** - управление базой знаний

## 🧠 KAG интеграция

### Что такое KAG?
KAG (Knowledge-Augmented Generation) - система на базе OpenSPG для:
- Структурированного хранения знаний
- Логических рассуждений
- Анализа связей между концепциями

### Образовательная схема
- **Student** - студенты
- **Lesson** - уроки
- **Assignment** - задания
- **Concept** - концепции/темы
- **Submission** - работы студентов

### Правила рассуждений
- `student-readiness.kgdsl` - готовность студента к заданию
- `assignment-difficulty.kgdsl` - сложность задания
- `concept-prerequisites.kgdsl` - предварительные требования

### Использование

```typescript
import { KAGClient } from './src/kag/client/KAGClient';

const client = new KAGClient({
  serverUrl: 'http://localhost:8887'
});

// Добавление урока
await client.addLesson(lessonData);

// Анализ готовности студента
const readiness = await client.analyzeStudentReadiness(studentId, assignmentId);
```

## 🛡️ Безопасность

### Режим DRY_RUN
По умолчанию агент работает в тестовом режиме:
- Открывает браузер (видимый)
- Находит задания
- Генерирует комментарии
- **Вписывает комментарий в поле, но НЕ нажимает кнопки**

Для включения боевого режима:
```typescript
// src/index.ts
const DRY_RUN = false; // ⚠️ Внимание!
```

### Переменные окружения
- Никогда не коммитьте `.env` файл
- Используйте `.env.example` как шаблон
- Храните API ключи в безопасности

## 🐛 Отладка

### Проблемы с парсингом
1. Проверьте URL в `.env`
2. Изучите селекторы в `src/parser.ts`
3. Запустите с `headless: false` и наблюдайте за браузером

### Проблемы с AI
1. Проверьте API ключи в `.env`
2. Проверьте лимиты API (Groq, Gemini)
3. Смотрите логи в консоли

### Проблемы с GraphRAG
1. Убедитесь, что Neo4j запущен
2. Проверьте подключение: `npm run inspect-kb`
3. Проверьте логи Neo4j
