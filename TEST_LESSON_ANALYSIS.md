# 🧪 Тестирование анализа урока

## Что будет выведено в консоль

### 1. При переходе к уроку

```
============================================================
📚 ШАГ 1: Анализ урока (ID: 344609228)
============================================================
📚 Загружаю содержимое урока ID: 344609228...
   📖 Урок: "AA06. Фильтры, задержки и условия"
   🔗 URL: https://university.zerocoder.ru/teach/control/lesson/view/id/344609228
   📄 Общий объем текста: 3450 символов
   🎥 Найдено видео: 3
```

### 2. Для каждого видео

```
   ✅ Видео 1: "Введение в фильтры"
      └─ Описание: 450 символов (до: 120, после: 330)
   ✅ Видео 2: "Настройка условий в Albato"
      └─ Описание: 380 символов (до: 0, после: 380)
   ✅ Видео 3: "Практический пример"
      └─ Описание: 520 символов (до: 200, после: 320)
```

### 3. Итоговая статистика

```
   📊 ИТОГО извлечено из урока:
      • Видео блоков: 3
      • Текстовых описаний: 3
      • Общий объем описаний: 1350 символов
      • Изображений: 2
      • Файлов: 1
```

### 4. Создание выжимки через AI

```
   🧠 Создаю выжимку урока через AI...
   ✅ Выжимка урока создана (287 символов)
   📝 Первые 150 символов: "В уроке рассматривается работа с фильтрами и условиями в платформе Albato. Показано, как настраивать фильтрацию данных по различным полям..."

✅ Урок успешно проанализирован!
🔙 Возвращаюсь в ленту ответов...
============================================================
```

### 5. Если урок не найден

```
⚠️ Урок ID не найден, пропускаю анализ урока
```

### 6. Если произошла ошибка

```
❌ Ошибка при загрузке урока: [описание ошибки]
⚠️ Продолжаю проверку без контекста урока...
```

## Что проверить

### ✅ Успешный сценарий

1. **Переход к уроку работает**
   - Видите URL урока
   - Видите название урока

2. **Парсинг видео работает**
   - Найдено хотя бы 1 видео
   - Для каждого видео есть описание

3. **Выжимка создана**
   - Видите "Выжимка урока создана"
   - Видите первые 150 символов выжимки

4. **Возврат в ленту работает**
   - Видите "Возвращаюсь в ленту ответов"
   - Проверка задания продолжается

### ⚠️ Проблемные сценарии

#### Проблема: Видео не найдены

```
   🎥 Найдено видео: 0
   ℹ️ Видео не найдены, парсим весь текст урока...
```

**Решение:** Урок текстовый или видео встроены иначе. Агент использует весь текст урока.

#### Проблема: Описания пустые

```
   ✅ Видео 1: "Видео 1"
      └─ Описание: 0 символов (до: 0, после: 0)
```

**Решение:** Нужно обновить селекторы в `src/lesson-parser.ts`. Откройте урок вручную и изучите HTML структуру.

#### Проблема: Ошибка API при создании выжимки

```
   ⚠️ Ошибка при создании выжимки: [ошибка]
```

**Решение:** Проверьте API ключ (GROQ_API_KEY или OPENAI_API_KEY) в `.env`.

## Отладка

### Сохранить HTML урока для анализа

Добавьте в `src/lesson-parser.ts` после загрузки страницы:

```typescript
// Сохраняем HTML для отладки
const html = await page.content();
fs.writeFileSync('debug_lesson.html', html);
console.log('   💾 HTML урока сохранен в debug_lesson.html');
```

### Сделать скриншот урока

```typescript
await page.screenshot({ path: 'debug_lesson.png', fullPage: true });
console.log('   📸 Скриншот урока сохранен в debug_lesson.png');
```
