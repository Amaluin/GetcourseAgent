## 📊 Что делает скрипт

1. **Авторизуется** в GetCourse используя существующую систему (browser.ts, auth.ts)

2. **Исследует текущую страницу:**
   - Пробует различные CSS селекторы для курсов, разделов, уроков
   - Извлекает ID, названия, описания, URL, порядок
   - Сохраняет примеры HTML структуры

3. **Анализирует навигацию:**
   - Ищет меню и breadcrumbs
   - Определяет паттерны URL
   - Документирует способы навигации

4. **Исследует альтернативные страницы:**
   - `/teach/control` - главная админки
   - `/teach/control/stream` - тренинги
   - `/pl/teach/control/stream` - курсы
   - `/teach/control/my-courses` - мои курсы

5. **Углубленное исследование:**
   - Переходит в найденные курсы для поиска разделов
   - Переходит в найденные разделы для поиска уроков
   - Документирует полную иерархию

6. **Сохраняет результаты:**
   - `research-results.md` - детальная документация
   - `research-results.json` - структурированные данные
   - Консольный вывод с статистикой
