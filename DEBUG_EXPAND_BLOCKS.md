# 🔓 Отладка раскрытия скрытых блоков

## Проблема

На странице урока есть раскрывающиеся блоки (спойлеры, аккордеоны) со стрелками ▶, которые скрывают часть контента. Их нужно раскрыть перед парсингом.

## Решение

Реализована функция `expandAllHiddenBlocks()`, которая:

### 1. Ищет элементы по селекторам

```typescript
// Стрелки в тексте
'span:has-text("▶")'
'div:has-text("▶")'

// Классы спойлеров
'.spoiler-title'
'.accordion-header'
'.expandable-header'

// Элементы с onclick
'[onclick*="toggle"]'

// Кнопки/ссылки
'a:has-text("Развернуть")'
'button:has-text("Показать")'

// Иконки
'.fa-chevron-right'
'.glyphicon-chevron-down'

// Bootstrap
'[data-toggle="collapse"]'
'.collapsed'
```

### 2. Кликает по каждому элементу

- Проверяет видимость
- Проверяет, не раскрыт ли уже
- Кликает с `force: true`
- Ждет 300ms на анимацию

### 3. JavaScript манипуляции

Принудительно показывает скрытые элементы:

```javascript
// Убираем display: none
element.style.display = 'block';

// Убираем классы collapsed, hidden
element.classList.remove('collapsed', 'hidden');
element.classList.add('expanded', 'show');

// Устанавливаем aria-expanded="true"
element.setAttribute('aria-expanded', 'true');
```

## Добавление новых селекторов

### Шаг 1: Откройте урок вручную

1. Перейдите к уроку в браузере
2. Нажмите F12 (DevTools)
3. Найдите элемент со стрелкой (Inspect)

### Шаг 2: Изучите HTML

Пример:
```html
<div class="custom-spoiler" onclick="toggleContent(this)">
  <span class="arrow">▶</span>
  Фильтры в Albato
</div>
<div class="custom-content" style="display: none;">
  [Скрытый контент]
</div>
```

### Шаг 3: Добавьте селектор

В `src/lesson-parser.ts`, в массив `arrowSelectors`:

```typescript
const arrowSelectors = [
  // ... существующие селекторы ...
  
  // Ваш новый селектор
  '.custom-spoiler',
  '[onclick*="toggleContent"]'
];
```

## Альтернативный подход: Скролл вниз

Иногда контент загружается при прокрутке (lazy loading).

### Добавьте в `expandAllHiddenBlocks()`:

```typescript
// Прокручиваем страницу вниз для загрузки lazy-content
await page.evaluate(() => {
  window.scrollTo(0, document.body.scrollHeight);
});
await page.waitForTimeout(1000);

// Прокручиваем обратно вверх
await page.evaluate(() => {
  window.scrollTo(0, 0);
});
await page.waitForTimeout(500);
```

## Частые проблемы

### Проблема 1: Элементы не кликабельны

**Причина:** Перекрыты другими элементами

**Решение:** Используем `force: true` в клике (уже реализовано)

### Проблема 2: Контент загружается через AJAX

**Причина:** После клика нужно ждать загрузки

**Решение:** Увеличить `waitForTimeout` с 300ms до 1000ms

### Проблема 3: Нестандартные спойлеры

**Причина:** Кастомная реализация на сайте

**Решение:** Добавить специфичные селекторы (см. выше)
