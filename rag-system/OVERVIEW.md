# 🎯 Обзор RAG системы для GetCourse Agent

## 📦 Что создано?

Полноценная система **GraphRAG** для автоматизации проверки домашних заданий с использованием:
- 🗄️ **Векторная БД** (Supabase + pgvector)
- 🧠 **AI Embeddings** (OpenAI text-embedding-ada-002)
- 🔍 **Semantic Search** (векторный поиск похожих работ)
- 💾 **Smart Caching** (кэширование уроков)
- 📚 **Knowledge Base** (база успешных решений)

```
4. Проверяем работу (10 сек)

```

### Последующие проверки (горячий кэш)
```
1. Берем урок из кэша (0.5 сек)
2. Ищем похожие работы (1 сек)
3. Проверяем работу (10 сек)
───────────────────────────
Итого: ~11.5 секунды ⚡
```

## 🎓 Ключевые концепции

### Embedding (векторизация)
Превращает текст в вектор (массив из 1536 чисел):
```
"GitHub Actions" → [0.123, -0.456, 0.789, ...]
```

### Vector Search (векторный поиск)
Находит похожие тексты по их векторам:
```sql
SELECT * FROM submissions
ORDER BY embedding <=> query_embedding
LIMIT 5;
```

### RAG (Retrieval-Augmented Generation)
AI проверяет работу с учетом:
- ✅ Контекста урока (из кэша)
- ✅ Примеров успешных работ (из БД)
- ✅ Идеального ответа

## 💡 Примеры использования

### Проверка работы с RAG
```typescript
import { checkHomeworkWithRAG } from './rag-integration';

const result = await checkHomeworkWithRAG({
  id: 'sub-123',
  lessonId: '345069174',
  assignmentId: 'assign-456',
  studentName: 'Иван Петров',
  submissionText: 'Я настроил GitHub Actions...',
  imageUrls: [],
  fileUrls: []
});

console.log(result.status);   // 'accept' или 'reject'
console.log(result.comment);  // Комментарий от AI
```


## 📦 Структура БД

### Таблицы
1. **lessons** - Кэш уроков (контент + embedding)
2. **assignments** - Задания (описание + идеальный ответ)
3. **student_submissions** - Работы студентов (текст + embedding)
4. **lesson_concepts** - Концепции из уроков (для GraphRAG)
5. **submission_concepts** - Связь работ с концепциями
6. **cache_stats** - Статистика использования кэша

### Функции
1. **match_lessons()** - Поиск похожих уроков
2. **match_accepted_submissions()** - Поиск похожих работ
3. **match_concepts()** - Поиск концепций
